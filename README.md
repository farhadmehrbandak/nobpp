# Project Name

simple c++ build system inspired by nob (Alexey tsoding)

## Features

* DLL, archive ,exe support for linux

## Requirements

* C++23
* GCC
* No external dependency

## Build

```bash
cc -std=c++23 nob.cpp -o nob
```

## Run

```bash
./nob
```
